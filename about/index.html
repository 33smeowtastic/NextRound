让面试准备留下可以反复练习的资产。

NextRound 是本地优先、离线可用的个人面试训练与备考工作区，适用于企业求职、公务员及事业单位招录。界面主要使用中文，开源 README 提供中英文说明。

打开 NextRound →

当前可以做什么

  • 整理岗位和招录单位、题目、答案、自我介绍及内容卡片。
  • 按天堂、人间、地狱难度抽题，计时练习、本地录音，并保存手动自评与复盘。
  • 关联面试现场问题与准备资料，追溯反馈并按透明规则比较岗位。
  • 预览统一 JSON 后再导入，保留重复/冲突边界；完整备份包含录音与附件。

AI 与应用如何配合

  1. 下载训练协议，在您选择的外部 AI 工具中完成首轮训练。
  2. 让 AI 使用整理模板输出结构化 JSON；核对内容，并移除不希望提供的个人信息。
  3. 回到 NextRound 预览导入，再进行本地复练、编辑和记录。

数据留在哪里

业务记录保存在当前浏览器来源的 IndexedDB。应用没有账号、云同步、内置模型调用、统计埋点或自动上传业务记录。向外部 AI 提供材料是用户主动操作，适用该服务的规则。

清除浏览器站点数据、使用隐私窗口或更换设备可能让您无法继续访问原记录。完整 JSON 备份未加密，请妥善保管并定期导出。

当前边界

当前没有独立的熟练度算法或间隔重复系统；自评由用户填写。Ritual 入口仍在建设中。真实手机传感器、真实麦克风与操作系统安装仍需对应环境验证。
