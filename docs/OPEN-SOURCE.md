# 开源源码交付

代码采用 MIT，版权主体为 Brothforge。插画、BGM 和品牌素材采用根目录 `ASSET-LICENSE.md` 的独立条款；第三方字体保留自身许可，下载协议与模板保留原文和原有使用说明。

## 两种交付

- `npm run build`：站点运行包，供静态 HTTPS 托管；包含运行资源和许可，不含维护文档及测试。
- `npm run build:source`：公开源码目录，包含可编辑源码、服务/构建脚本、现役测试、固定开发依赖、当前文档和许可。它可独立执行 `npm ci`、`npm run check`、`npm test`、`npm run test:browser` 和构建。

每次构建生成新的 `dist/nextround-public-<UTC时间>/` 或 `dist/nextround-source-<UTC时间>/`，拒绝复用已有目标，避免旧私人文件残留。`release-manifest.json` / `source-manifest.json` 只列相对路径、大小、hash 和构建信息，不记录本机绝对路径。

## 保留在本地的内容

历史 `docs` 阶段目录、机器操作脚本、生成记录、原稿与候选、旧截图、测试输出及 `.impeccable` 保留在维护者本机。公开源码由白名单收录，不递归复制这些目录。`.gitignore` 与源码白名单同步，使当前目录首次添加文件时也不会默认收录它们；仍应审阅实际暂存内容，构建不会替代 Git 审阅。

不删除或改写本地历史，不沿用历史脚本里的关机或机器维护操作。原始下载协议及模板按字节保留，其中 V1.2 模板额外作为导入格式回归夹具收录；它不是候选图片或用户业务备份。

## 检查边界

公开构建在写出前检查机器路径和常见凭证签名；该扫描是补充检查，不能证明所有隐私风险均已排除。公开源码不收录历史截图，因此不以抽样截图检查宣称整个历史图库已脱敏。现役素材的 EXIF/文本元数据及音频标签已检查；业务数据由使用者自己的 IndexedDB 与备份管理，不进入源码导出。

浏览器检查使用非持久化新上下文和临时 loopback 来源，不使用真实用户档案。生产 HTTPS 和基础响应头已验证；真实麦克风、真实手机传感器、操作系统安装与存储配额耗尽仍需在目标环境验证。详细命令见 [测试说明](TESTING.md)。

本次开源准备的逐项结论见 [发布前审计](RELEASE-AUDIT.md)，站点抓取和正式域名边界见 [SEO说明](SEO.md)。CI与问题模板已作为源码提供；不会由本地构建自动创建公开仓库、Tag、Release或部署。

## 正式版本与分支流程

首个正式上线版本为 `1.0.0`，对应 `v1.0.0` Tag；公开仓库为[33smeowtastic/NextRound](https://github.com/33smeowtastic/NextRound)，首发main与版本分支使用同一提交，详情见[首发记录](releases/v1.0.0.md)。后续版本在对应版本分支开发、构建并上线验证，确认无问题后才合并到 GitHub `main`；Tag、Release 和上传产物对应已验证版本提交。本地构建不会执行 Git 写入、公开发布或生产变更。
