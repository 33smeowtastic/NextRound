# UI 与离线验证

当前行为以源码、实际渲染及可复跑测试为依据。公开版本包含现役测试源码，不收录历史截图、生成记录或本机阶段报告。执行方式见 [测试说明](TESTING.md)。

- 界面规范：`tests/ui-standards-browser.mjs` 检查 A/AA 自动规则、语义、键盘、焦点、弹窗和小屏几何；具体依据与边界见 [前端规范](UI-STANDARDS.md)。
- 场景配准：`tests/portal-registration-browser.mjs` 覆盖 320/390/507/1280/1440px、双主题、图片解码、实际离线刷新和指南，以及训练室两张主题图的离线解码与旧图缓存退役。
- 训练室主题：`tests/navigation-training-browser.mjs` 对比当前首页实际图片来源，覆盖320/390/1440px的即时切换和往返恢复。
- 空间隔离：`tests/training-finish-workspace-browser.mjs` 覆盖慢保存期间尝试切空间；`tests/async-workspaces.test.js` 覆盖任务锁、异步失效及旧编辑器保护。
- 导入安全：`tests/import-security-browser.mjs` 通过真实备份文件输入覆盖不可信 ID、评分、附件、追溯、搜索、刷新和空间隔离。
- 指南与设置：仓库内原始协议/模板对比、下载、复制、导入、清空确认与取消。
- 交互：鼠标和模拟重力、减少动态、关闭动效、导航与双曲播放由现役 suite 覆盖。录音测试使用虚拟设备，不代替真实麦克风验收。

测试产物统一写入忽略的 `test-results/`；单次结果只证明对应源码、环境和运行范围。历史检查通过不等于后续代码自动通过。浏览器运行默认禁用 GPU，采用短时普通预览。

生产HTTPS/基础响应头已完成上线检查，1.0.2正式域名3组浏览器回归及92个文件哈希通过，详见[部署记录](DEPLOYMENT.md)。尚未验证真实手机传感器、真人声音听感、系统安装确认及存储配额耗尽。音频元数据清理已验证压缩音频数据与解码 PCM 不变，不以这项校验代替真人听感。
