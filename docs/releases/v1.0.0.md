## 首发与分支 / Initial branches

本次首发 `main` 与 `codex/release-v1.0.0` 使用同一最终版本提交，`v1.0.0` 标记该提交。Cloudflare Pages 项目 `nextround` 的生产分支为 `codex/release-v1.0.0`，部署元数据记录实际提交 SHA。确切 SHA、部署标识和产物 SHA-256 以该 GitHub Release 及其附件为准。

The initial `main`, `codex/release-v1.0.0` and `v1.0.0` identify the same final release commit. Cloudflare deployment metadata identifies that commit. The GitHub Release records the exact commit, deployment ID and artifact checksums.

后续版本在各自版本分支开发、构建和上线验证；确认线上正常后才合并 GitHub `main`。本次首发是这个流程的初始基线。

Future versions are developed, built and deployed from their version branches, verified online, then merged into GitHub `main`. This initial release establishes that baseline.

- 正式来源完成首用、导入/训练/恢复、薪资编辑、设置、加载与实际离线刷新、UI规范、无JavaScript中英介绍和检索入口的浏览器检查，均使用隔离虚构档案。 / Production checks cover onboarding, imports/practice/restore, salary editing, settings, loading/offline refresh, UI standards and script-free bilingual descriptions using disposable fictional archives.

线上检查发现测试在远程CSS下载完成前读取颜色。已修正测试等待条件，并在真实来源复验；产品配色和业务数据逻辑未因该测试修复改变。

A production check exposed a test reading colors before remote CSS finished loading. The test now waits for its stylesheet and has been rerun; product colors and business-data logic are unchanged by that fix.
