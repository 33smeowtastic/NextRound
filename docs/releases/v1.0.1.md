# NextRound 1.0.1 — SEO ownership verification

本次补丁为 Google Search Console 与 Bing Webmaster Tools 提供首页所有权验证标签。标签是平台要求公开的站点验证值，不是 API 密钥、用户资料或登录凭据。

This patch publishes homepage ownership-verification tags for Google Search Console and Bing Webmaster Tools. These are public verification values, not API keys, account data or login credentials.

- 版本分支 / Version branch: `codex/release-v1.0.1`.
- 先从版本分支构建和部署，检查正式来源及平台验证后，再合并 `main`。 / Deploy and verify the version branch before merging `main`.
- `v1.0.0` 及其首发产物保留。 / The original tag and release assets are preserved.
- 业务数据 Schema、导入格式、界面、品牌及本地档案处理不变。 / Data schemas, import formats, interface, branding and local archive behavior are unchanged.

生成器仅接受 Google/Bing/Baidu 三个已知验证字段和合法公共 token，只向首页 head 输出标签；缺省不输出，未知字段和非法内容会被拒绝。源码/站点构建仍在内存中生成，不自动修改工作副本。

The generator accepts only the three known providers and valid public tokens. Tags appear only in the homepage head. Unknown fields and invalid values are rejected, and builds remain deterministic without mutating the source tree.

本轮独立上线审计为39/39检查、45/45模拟检索请求通过。覆盖Google、Bing、百度、OpenAI、Claude与Perplexity的公开检索入口；模拟UA不等于官方爬虫已经访问或平台已经收录。百度站长提交因平台强制实名认证，按维护者选择暂不执行；原搜索访问允许规则保留。

The independent post-launch audit passed 39 checks and 45 simulated retrieval requests. This verifies access preferences and HTTP behavior, not actual official-bot visits or indexing. Baidu submission is deferred at the maintainer's choice because its platform requires identity verification; public search access remains allowed.

具体提交结果与尚未确认的索引状态见 [SEO说明](../SEO.md)。

Google/Bing所有权验证通过，两家已接受站点地图及三个公开URL的单页索引请求；Google地图成功发现3页，Bing地图仍处理中。实际收录与AI引用尚未证实。英文description按Bing实时提示精简至140字符；装饰图保留正确的空alt。

Google and Bing verified ownership and accepted the sitemap and individual indexing requests for all three public URLs. Google discovered all three; Bing's sitemap was still processing. Actual indexing and AI citations remain unconfirmed. The English description is now 140 characters; decorative images retain appropriate empty alt text.
