# 用虚构资料体验完整准备流程

配套文件：[interview-prep.json](interview-prep.json)。请下载并选择 **JSON 文件**导入；这份 Markdown 用于阅读，不是可导入的数据文件。

“纸舟读书角”是为本仓库编写的假想练习场景。下面的任务、回答和判断全部虚构，没有使用真实简历、个人联系方式、雇主或面试记录。它们演示表达结构，不能当作自己的真实经历使用。

## 先导入，再复练

1. 从首页进入 Interview 正式档案，打开“知识库”。全新档案会显示四步指南；其中可下载 AI 训练协议和整理模板。此示例已经整理好，不需要使用外部 AI、简历或账号。
2. 点击“导入”，选择 `interview-prep.json`。在预览中核对三道题及状态，再点击“确认导入”。如仅看到源码网页，请先把文件保存为 `.json`；不要把 Markdown 或代码块围栏一起粘进文件。
3. 在知识库搜索“整理任务”，打开题目，试着修改回答并保存。也可以使用题目左侧的难度控件调整分级。示例初始包含天堂、人间、地狱各一道题。
4. 打开“训练室”，展开“本次训练”，分别选择天堂、人间、地狱，再抽取题目。阅读底稿、自己练习表达，点击“开始训练”；完成后点击“完成复盘”，填写自评与改进备注。
5. 刷新页面或关闭当前标签页后，在同一浏览器、同一站点地址重新打开，已保存题目与训练记录仍可读取。隐私模式、清除网站数据或更换来源地址可能丢失或隔离档案。
6. 在“设置 → 档案与备份”导出完整备份并保管。恢复完整备份使用备份区的“增量导入”或“替换导入”，不使用知识库的 AI JSON 导入入口；替换前会要求确认，并覆盖当前空间，请先备份。

自评是你手动记录的训练反馈。当前没有自动熟练度判定、间隔重复计划（SRS）或录用预测；题目难度也不等于个人熟练度。录音可选，此示例不要求麦克风权限。

## 文件格式与增量规则

- 统一导入标识为 `next-round-unified-1.2`，兼容字段 `version` 为 `4.0.1`。它们与应用软件版本、Markdown 模板文件名里的版本号是不同概念。
- 文件完整保留 `companies`、`jobs`、`questions`、`introductions`、`cards`、`schedules`、`interviews` 七个模块数组；本示例只有 `questions` 非空，不创建公司、岗位、人物或面试档案。
- 重复导入未修改的同一文件会识别为重复，不会再增加三道题。空数组不清空现有资料；加入不同稳定 ID 的题目会增量添加。
- 本机已经编辑过的同 ID 题目会出现冲突，默认保留本机。只有明确选择采用导入版才会更新，旧版本仍保留为冲突快照。不要通过改 ID 来覆盖原题。
- 同一文件内重复 ID、必填字段不完整、非法 JSON 或未知 Schema 会在写入前报错或在预览中标为无效。请依据提示修正；不要为绕过错误改动应用的数据格式。
- 未提供的可选关联用 `[]`；示例没有岗位关联。旧版 `易 / 中 / 难` 是兼容读取的历史分级，需要人工确认，新的示例使用天堂／人间／地狱。

## 来源 Markdown：三个完全虚构的练习素材

以下文本是配套 JSON 的阅读版，便于核对题目、分类和完整回答。无需把它上传给任何服务。

### 1. 自我认知 · 天堂

**题目：**请用三句话介绍虚构练习中的“纸舟读书角”整理任务。

**示例回答：**【完全虚构的示例回答】纸舟读书角是一处假想的共享阅读空间，练习目标是让借阅者更容易找到书。我在练习中负责把杂乱书目按主题整理，并设计清晰的书架标签。讲述时先说明目标，再说明自己的行动，最后指出仍需通过实际观察验证效果；这里没有真实任职经历或成效数据。

### 2. 项目经历 · 人间

**题目：**在“纸舟读书角”的虚构练习中，怎样处理分类方式的不同意见？

**示例回答：**【完全虚构的示例回答】假想团队分别建议按作者和按主题分类。我会先明确借阅者的查找任务，再为两种方案各做一小组纸面样例，请参与练习的人用相同问题尝试查找。比较反馈后记录选择理由；如果没有测试数据，就把判断标为待验证，不编造效率提升或用户满意度。

### 3. 情景应对 · 地狱

**题目：**假设“纸舟读书角”的预约提示可能误导使用者，而发布期限很近，你会怎样取舍？

**示例回答：**【完全虚构的示例回答】我会先确认误导会造成什么后果，并区分已经观察到的事实与尚未验证的假设。优先改正可能让人误以为预约成功的提示，给出明确的确认状态和人工核对办法，再与假想团队约定其余改动的优先级与回退方式。最后说明判断依据和未解决的问题，而不是承诺所有风险都能在期限前消除。
